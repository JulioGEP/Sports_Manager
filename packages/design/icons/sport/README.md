# Iconos de deporte

Ocho iconos propios para lo que no cubre la librería base (Phosphor, peso duotone).
Misma rejilla de 24 px y trazo de 1,75.

- Trazo: `currentColor`. Pon el color con la clase de texto del contenedor.
- Relleno duotono: `var(--icon-duo)`, lo genera el motor de color del club.

Impórtalos como componentes de React (por ejemplo con SVGR). Si los usas como `<img>`,
las variables CSS no llegan al SVG y el relleno no se verá.

Archivos: balon, silbato, cronometro, trofeo, camiseta, pista, pesa, prueba-fisica.
